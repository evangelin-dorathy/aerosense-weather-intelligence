System Architecture

AeroSense operates on a lightweight Flask REST backend, processing over a decade of meteorological records from Szeged, Hungary. The system executes serialized scikit-learn models for real-time environmental forecasting.

01 / Rain Classification

Evaluates temperature, apparent temperature, humidity, pressure, and wind speed to determine precipitation likelihood.

02 / Thermal Regression

Applies daily aggregated time-series lag features (T-1, T-2, T-3) to regress next-day average temperature.

03 / State Categorization

Multi-class identification categorizing physical indicators into Clear, Cloudy, Rainy, or Foggy states.

04 / Data Aggregation

Pre-computes seasonal and monthly distributions for zero-latency dashboard rendering.
